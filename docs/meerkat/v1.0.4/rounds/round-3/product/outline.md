## 第一章 研究背景、方法与数据来源说明
**字数下限：8,000**

### 1.1 研究背景与意义
- 照明行业从"照明"到"光环境"的范式转变
- 欧普照明在中国照明行业的地位与代表性
- 研究目的：为欧普照明管理层/投资者提供竞争情报

### 1.2 研究范围与边界
- 时间范围：2016–2025 年（核心分析 2021–2025）
- 地理范围：中国市场为主，兼顾全球市场
- 品类范围：通用照明、装饰照明、智能照明、工程照明、商业照明

### 1.3 研究方法与框架
- 波特五力模型
- SWOT 分析
- 战略群组分析
- 财务对标分析
- 技术参数横向对比

### 1.4 数据来源与可信度评估
- 上市公司年报/季报（欧普照明 603515.SH、佛山照明 000541.SZ、阳光照明 600184.SH、公牛集团 603100.SH）
- 行业报告（奥维云网 AVC、中商产业研究院、智研咨询、GGII）
- 政府标准与政策文件
- 专利数据库（CNIPA、WIPO）
- 数据来源可信度分级（A 级：年报/官方统计；B 级：券商研报/行业协会；C 级：媒体/公开报道）

### 1.5 关键术语定义
- 通用照明 vs 装饰照明 vs 智能照明
- HCL（人因照明 Human Centric Lighting）
- CR3/CR5（市场集中度）
- 光源效率（lm/W）

## 第二章 中国及全球照明行业全景
**字数下限：10,000**

### 2.1 全球照明市场规模与增长
- 2020–2025 年全球照明市场规模（金额 + 出货量）
- 主要区域市场：北美、欧洲、亚太、拉美、中东非
- LED 渗透率与替换周期

### 2.2 中国照明市场规模与结构
- 2016–2025 年中国照明市场规模趋势
- 通用照明 / 装饰照明 / 智能照明 / 商业照明 / 工程照明细分占比
- 人均照明消费与发达国家对比

### 2.3 产业链结构分析
- 上游：LED 芯片（三安光电、华灿光电、晶元光电）、驱动 IC、铝基板、光学透镜
- 中游：灯具制造与品牌运营（欧普、雷士、佛山照明等）
- 下游：零售渠道、工程渠道、电商渠道、出口
- 价值链利润分配

### 2.4 政策与标准环境
- 中国能效标准（GB 30255-2024 等）
- "双碳"目标对照明行业的影响
- 智能家居相关政策（Matter 协议引入、全屋智能标准）
- 出口市场标准（EU Ecodesign、Energy Label、UL、CE）

### 2.5 技术演进路线
- 白炽灯 →  CFL → LED → 智能照明 → 人因照明
- Mini/Micro LED 在照明领域的应用前景
- 可见光通信（VLC）与 Li-Fi

## 第三章 欧普照明公司深度剖析
**字数下限：10,000**

### 3.1 公司概况与发展历程
- 创立背景（1996 年，王耀海、马秀慧）
- 关键里程碑时间线
- 吴江（苏州）生产基地建设（亚洲最大照明工业园）
- 上市历程（2016 年上交所 IPO，股票代码 603515）

### 3.2 股权结构与公司治理
- 前十大股东（王耀海、马秀慧及一致行动人）
- 管理层架构与核心高管
- 董事会构成与独立董事

### 3.3 业务结构与产品线
- 照明产品：基础照明（吸顶灯、筒射灯、面板灯）、装饰照明（吊灯、壁灯）、功能照明（厨卫灯、台灯）
- 电工电料：开关插座、布线系统
- 智能产品：智能吸顶灯、智能筒射灯、智能场景面板
- 工程渠道产品
- 各产品线营收占比与增速

### 3.4 渠道结构分析
- 线下经销网络：终端网点数量、区域分布
- 电商渠道：天猫、京东、拼多多等平台表现
- 工程集采：房地产精装配套、公共建筑
- 海外渠道：欧洲、东南亚、中东市场布局

### 3.5 财务分析（2021–2025）
- 营收与利润趋势（基于已获取数据：2024 年营收 70.96 亿元，同比 -8.96%；2025 年营收 69.70 亿元，同比 -1.78%）
- 毛利率变化（2021 年 32.43% → 2024 年 39.16%）
- 净利率与 ROE
- 研发投入（3.2–3.5 亿元/年，占营收 4.5–5%）
- 现金流与资产负债结构
- 分区域营收（国内 vs 海外）

### 3.6 战略路线与核心竞争力
- "照明 + 电工 + 智能"三位一体战略
- 品牌定位：大众消费级照明领导品牌
- 核心竞争优势：品牌认知度、渠道覆盖、供应链规模效应
- 战略挑战：房地产下行、电商价格战、智能转型

2. **非上市竞品财务数据**：雷士照明、三雄极光（北交所）等非沪深主板公司的详细财务数据需通过其他渠道获取，大量标注 [待核实]。
3. **市场份额数据**：中国照明市场具体份额数据需检索行业报告，暂时标注 [待核实]。
4. **行业数据多为区间值**：中商产业研究院、智研咨询等机构发布的行业数据多为区间估算值（如"3,000–3,200 亿元"），在报告中需明确标注为估算值。

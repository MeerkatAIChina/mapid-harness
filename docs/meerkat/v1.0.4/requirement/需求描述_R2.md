## 1. 背景

调优 Loop R1（v1.0.3）建成了基础设施：金缺陷集 + 检查器 + 三层评审链（尺子），
合并/统计工具、耐心重试、日期注入、记忆隔离（机制）。R1 严格闭环，
机制层缺陷（字数失真、合并膨胀、日期错误、记忆污染、断流人工盯守）全部解决且实证。

R1 快速轮（5 章 / 3.2 万非空白字符）同时暴露：**内容质量层缺口仍在**。
Loop 自此进入稳态——Rn 打 Rn-1 量出的缺口。R2 是稳态第一枪。

## 2. 问题陈述（全部有实测依据）

| # | 缺口 | 实测证据 | 严重度 |
|---|---|---|---|
| P1 | 无来源精确数据：模型写精确数字但不标来源、不按红线标 [待核实] | 快速轮产物 **57 条** unsourced_precise（快速轮验收记录 §四） | 高——咨询报告致命伤 |
| P2 | 图/表缺来源题注或解读 | 快速轮产物 **13 条** figure_companion（同上） | 中 |
| P3 | 台账登记漏章：章节数据未以「首现章节」登记台账 | 快速轮 **1 条真阳性**（第 3 章财务数据，同上） | 中——跨章一致性的锚松动 |
| P4 | 口径错置型事实错误：分部→集团、旧预测值未更新、分子分母口径不一致 | 基线金缺陷深审 7/7 的反复模式（深审层回归报告洞察） | 高——随机编造之外的系统性错误模式 |
| P5 | 尺子自身的洞：金缺陷集无 D7（图表配套）型缺陷，该维度检出率无回归基准 | 回归报告_检查器层 §建议 | 中——无尺可量 |
| P6 | 体量缺口：v3 全量轮产出 66,974 字符 = 10 万字目标的 67%（R0/v2 为 141,437） | round-2 基线轮验收记录 §四 | 高——10 万字是项目核心交付物 |

## 3. 目标（R2 验收方向，具体线在设计文档定稿）

1. P1~P4 缺口在全量轮产物上收敛，**定调按「行为类清零、能力类降幅」二分**（用户裁定 2026-10-20）：

   | 缺口 | 类型 | 验收定调 | 理由 |
   |---|---|---|---|
   | P1 无来源未标注 | 行为类 | **清零**：「无来源且未标 [待核实]」= 0；无来源但已标 [待核实] = 合规态，不计数 | 标注是提示词可驱动的行为，检查器可闭环验证；P1 的合格态不是「所有数字有来源」 |
   | P2 图表配套 | 行为类 | **0**（增量口径，沿用 R1 排除基线固有噪声的口径） | 题注是模板化行为 |
   | P3 台账漏章 | 行为类 | **0** | 台账是跨章一致性的锚，一条不漏是底线 |
   | P4 口径错置 | 能力类 | **降幅 ≥80%（方向）**，附「结论章对标表口径错误 = 0」 | 受模型事实把握能力边界约束，一轮清零不现实；不给 impossible target |
   | P6 体量缺口 | 行为类 | **达标**：非空白字符 ≥ 10 万字目标（章节字数下限刚性约束） | 缩量尺度已达标（快速轮），全量尺度失守属行为约束缺失，提示词可驱动 |

   （P6 于 2026-10-20 用户裁定纳入 R2——需求 §4「不扩大战场」的例外：体量是项目核心交付物，
   且手段（每章字数下限刚性条款）与 v4 提示词改动包同层，边际成本极低。）

   具体数字待基线全量分布出来后校准（设计阶段），二分定调先行。
2. **首次全量轮**：真 10 万字 + 三层评审验收（快速轮缩量版不能回答质量是否达标）；
3. P5：金缺陷集增补 D7 型缺陷，回归口径覆盖图表维度；
4. 全程 0 人工干预（R1 机制沿用，T4 已拔测实证）。

## 4. 非目标

- 不新建基础设施（R1 已建好且实证可信，只做必要的增补）；
- 不改 Octop 内核（延续插件/自有模块挂载，触及内核须 ADR）；
- 不扩大战场：R2 只打 P1~P5，新发现的缺口记录进 R3 输入，不在 R2 顺手修。

## 5. 候选手段（调研后再定，此处仅列方向）

- 提示词 v4：来源标注红线加码；关键数据强制注明「口径主体 + 数据期」（直接对 P4 的洞察）；图/表题注模板；
- 检查器增补：若提示词约束需要新检查器配合验证，按 TDD 增补；
- 金缺陷集增补 D7 型缺陷 + 回归复跑；
- 全量轮跑轮与三层评审验收（考场）。

**执行序（用户裁定 2026-10-20，含顺序依赖）**：

```
需求调研 → D7 增补 + 回归复跑 → 基线全量轮(v3) + 三层评审（建基线 + 拿 P4 分布）
→ 用实测分布定量化线 → 设计文档 → 提示词 v4 改动包 → 验证全量轮(v4) → 验收
```

- **P5 的 D7 增补必须在基线全量轮之前完成**：否则基线轮的 figure_companion 计数用旧
  检查器口径，D7 增补后口径一变基线作废，白跑一轮；
- **基线全量轮用 v3 提示词**（未改动状态），承担三份职责：建 P1~P4 全量基线分布、
  顺手拿 P4 深审分布（不单独补快速轮深审——5 章缺财务对标章与结论章，恰是口径错置
  最浓处，快速轮分布不能外推）、首次全量三层评审完整演练（提前暴露验证轮评审风险）；
- 全量轮 78 分钟是机器时间（0 人工干预已实证），人工成本约 30 分钟评审，可接受。

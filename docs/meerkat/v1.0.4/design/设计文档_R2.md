## 3. v4 改动包设计（**仅提示词层**，工具/机制/检查器零改动）

### C1 口径条款（打 P4，深审洞察驱动）

每个关键数据首次出现必须带「口径主体 + 数据期」，份额/集中度类数字必须写分母口径：

> 所有关键财务与市场数据首次出现时，必须注明**口径主体与数据期**，
> 格式：「主体 + 数据期 + 指标 + 数值」（例：欧普照明 2024 年报营收 70.96 亿元）。
> 市场份额、集中度（CR n）类数字必须注明**分母口径**（整体市场 / 细分品类 / 渠道类型），
> 未注明分母的份额数字禁止出现在结论章。

依据：E2（数据期错置）、E1/S2（分母缺失）、E7/E8（主体错置）。

### C2 来源标注强化（打 P1，行为遵守而非规则缺失）

红线 v3 已有（L69-71），遵守不均（财务章标、行业章不标）。改动 = 结构与刚性，不是新规则：

1. 把来源红线从「章节自检三问」**前移为段落级动作**：每个含精确数值的段落写完立即检查来源；
2. **结论章专项**：结论章每条数字论据必须标注出处章节（「（见第 X 章）」），且数值必须与该章一致——直接对 E1/E9 跨章矛盾；
3. 「先搜后写」与「无来源即标」绑定：搜不到 → 标 [待核实]，禁止凭印象填数。

### C3 题注模板（打 P2，模板化替代原则声明）

> 每张表格之后必须紧跟两行：
> `> 数据来源：<来源名>（<数据期>）` 和一段 ≥2 句的「数据解读」（说明该表支撑什么判断）。
> 无来源行或无解读段的表格视为未完成，不得进入下一节。

依据：135 条抽样全为「缺来源标注」型；模板化行为比原则性声明更容易稳定执行（调研 §2）。

### C4 台账登记刚性（打 P3）

把自检三问从「写完自问」改为「行动顺序」：**每章写完 → 先把本章关键数据登记进 data_ledger（含首现章节列）→ 才允许开始下一章**。依据：全量尺度 9/13 章漏登，行为随任务变长而衰减。

### C5 每章字数下限（打 P6）

**两级设计（评审裁定 2026-10-20）**：章级下限合计 ≥105,000 是**行为驱动**（让模型按分配写够），
合并前 ≥100,000 是**验收硬线**（兜底闸门）。5% 余量吸收「章级达标后的微小方差」，
**不吸收行为性欠账**（那由每章 report_stats 实测 + 加厚循环兜）。不硬卡 100,000 整：
各章下限之和 = 门槛意味着恰好压线才通过，任何一章轻微欠收就触发整章重写循环，不划算
（plan with buffer, gate at target）。

outline 阶段为每章分配非空白字符下限；**每章写完立即 report_stats 实测，低于下限必须
加厚重写该章后才可继续**；合并前 report_stats 总量 ≥100,000 才允许调用 merge_chapters。
依据：模型「写完结构就收工」（34 分钟 vs 基线 78 分钟）。

### C6 [待核实] 后续动作（深审新洞察，合规 → 可用）

> 财务核心表格（营收/利润/毛利率对标表）的主体数据必须先经检索获取；
> 检索不到时进入**三段式降级（评审裁定 2026-10-20）**：
> ① [待核实] 格子 ≤20% → 保留表格；
> ② >20% → 先「**删行保表**」：剔除无据的行，并注明覆盖范围（如「覆盖 7/10 家企业」）；
> ③ 删行后仍 >20% → 才整表降级为定性文字表述。
> **20% 的分母 = 该表数据格总数**（不含表头、单位、备注行）。
> [待核实] 永远是最后手段，不是默认选项；宁可待核实，不可编造。

依据：09 章 115 处标注让大表接近空表，合规但不可用。删行保表的理由：可用性损失来自空格
而非行数；有合规出口的禁令遵守率更高（与 C2「搜不到→标待核实」同构）。

## 4. 验证设计

1. **验证全量轮（v4）**：同一实验 agent、同一任务（欧普照明竞品分析）、v4 提示词；
   轮次准备检查单照旧（记忆/workspace 隔离）；
2. **判定**：检查器层对照 §2 量化线（P1/P2/P3/P6）；Claude 深审同范围（12+09 全审 + 03/05 抽样）判定 P4；
3. **尺子自检**：金缺陷回归复跑一遍（确认检查器版本未变、基准仍 TP 10/10）——提示词改动不影响尺子，但惯例确认；
4. **副作用监控**（C5 的已知风险）：字数下限可能催生注水/生成退化——degeneration 检查器 +
   深审顺带看「加厚段」质量；C1/C6 增加检索量 → 轮时长预计超 78 分钟，T4 断流预算已实证。

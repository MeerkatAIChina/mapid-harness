## 1. 背景

R3 拆分判定：**门禁机制通过、产物质量不通过**。行为纪律类问题（来源缺失/台账漏登/复制凑字）
已被机制根治；问题性质推进到「真实性」层——模型会给编造内容配上格式完美的假来源。
同时产品形态仍停留在纯 Markdown，不具备交付能力。

R4 两条主线：**真实性攻坚**（回源核验）+ **成品交付**（渲染/图表/引用样式）。

## 4. 冲突预警与改造点（设计阶段必须解决）

| 冲突 | 说明 | 改造方向 |
|---|---|---|
| **C5 引用样式 vs 检查器** | 现有 unsourced_precise 检查器按「数值 ±2 行内有来源标注」判定；改章末参考资料后，正文数值附近只剩引用标记 | 检查器改**三级**判定：①正文精确数值须带引用标记（如 [3]）；②**悬空引用**：正文 [3] 在章末参考资料须有对应条目；③**孤儿条目**：章末条目须被正文引用（凑数假装饰）。后两种正是假来源温床。**GD-06（无来源数据）判定逻辑同批改造；顺序钉死：先改引用格式、再改检查器——顺序反了金缺陷回归全崩** |
| **C5 vs 假来源** | 参考列表集中化让假来源更易隐藏（读者不逐条核对） | A1 优先级再升；参考条目格式强制含可核验要素（报告名/年份/机构） |
| **续写循环 vs 诚实出口** | 同事管线硬下限+8 轮续写；v5 刚立诚实出口且实证有效 | 续写为首选（不足先触发补写），诚实出口兜底（仍不足如实说明），退化检查守卫（防续写诱导凑字） |
| **硬失败 vs N=2 放行** | 同事管线全硬失败；R3 实证放行漏网 1 条 | 分类处置：无裁量项（残留/占位符/逐字重复）硬失败无放行；需权衡项保留 N=2 + A4 落盘追踪 |
| **审校链接入点** | 审校修改必须重过检查器 | 接入点 = merge 前；现有状态机已支持（改章→置待评→复测），零内核改动 |
| **审校上限** | 同事管线每章最多 4 处编辑——TRIZ 报告实证一章错误可超 4 处 | 取消硬上限，改为「问题回流修复队列」，由门禁驱动修复 |
| **图表接台账** | 同事规则「用章节已有数值」太松 | 升级为「图表数据必须来自台账条目或标注教学示意」；caption 强制带数据性质标注 |

## 5. 验收线草案（评审前初拟）

- R3 既有线全继承（P1/P2/P3/P7 = 0，P4 ≤ 2，M 金缺陷回归全绿 + GD-21/22 增补）；
- 新增：三格式同源且齐备（文件大小/页数/媒体数断言）；HTML 视觉审查通过；图表零装饰性配图（深审）；
  残留禁词（含中文模式）= 0；占位符 = 0；引用三级判定（标记/悬空/孤儿）= 0；
- **回源核验准确率分层定调**：硬事实（上市状态、并购事实、公司主体名称）**零容忍 = 100%**——
  错一条即致命伤；一般财务数值 **≥ 90%**（具体阈值设计阶段定，分层定调现在钉死）；
- **过程线重估（不沿用 160 分钟）**：续写前台化 + 审校链 + 回源核验 + 三格式渲染全是加时工序，
  round-4 光有效生成就 154 分钟。重估为「有效生成 200 + 工序 100」≈ **300 分钟级**。
  **口径钉死：预算算有效生成时间，不算墙钟**——看门狗上线后挂起被主动打断，
  挂起与恢复时长不计入预算，但计入事故记录；无看门狗兜底前的挂起另算。

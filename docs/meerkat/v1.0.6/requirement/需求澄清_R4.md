> 版本：v1.0.6 · 2026-11-03 · 对应 `需求描述_R4.md`、`需求调研_R4.md` §7 四议题

## 议题 ② 回源核验：触发范围与成本（最先定，它决定其余三题）

**定稿：三层防线，各管一段，谁也替不了谁。**

| 层 | 职责 | 范围 |
|---|---|---|
| **章级（主战场）** | 新增第五道章级工序「承重断言核验」 | 承重断言**全核**（一章 3~8 个离散硬事实：上市/并购/实控人/主体名称/关键年份），真伪二值、检索成本低 |
| **merge 前** | 跨章复查（同一事实两章打架、台账同指标两值） | 现有 numeric_consistency + structure 已在此 |
| **交付前** | 只查形式（占位符/残留/格式），不查事实 | 兜底 |

**核心原则**：时间窗口就是修复成本——假来源在章级拦是改一段话，merge 时拦是改半本书。
**判定三档分治**：

- **证实** → 通过；
- **证伪**（查到证据证明是假的）→ 必须删改，没有商量；
- **查无实证**（没检索到 ≠ 不存在）→ 允许保留内容，但**不许保留原断言强度**：
  「Yeelight 已上市」降级为「未检索到其上市信息」并标 [待核实]。

**举证责任在断言方**：断言真伪由证据说了算，拿不出证据就不许写得言之凿凿。
**额度**：核验失败与来源格式修复**共用本章 N=2 总预算**（防死循环，按章一个总预算最简单）。

## 议题 ① 审校模型选型

**定稿：一个独立模型打两份工，两道工序分开走。**

| | 事实核验（承重断言） | 逻辑审校（审校链 B1） |
|---|---|---|
| 干什么 | 对外求真：断言对真实世界 | 对内求一致：排名矛盾/计算错误/前后打架 |
| 靠什么 | **外部证据**（检索 + 正文抓取 + 比对） | **文本本身**（读、算、比，不检索） |
| 输出 | 证实/证伪/查无实证 + 证据链 | 行号 + 最小替换（禁整章重写） |
| 时机 | **章级**（趁上下文热，修复半径一节） | **merge 前**（跨章矛盾此时才可见） |

**顺序：先事实核验，后逻辑审校**——承重断言是假的，基于假数据的排名计算全是无用功。
审校发现事实疑点**回流核验队列**，不独自判。
**同一模型可接受的理由**：两工序证据来源不同（外部检索 vs 文本推理），知识盲区不会同时在两处
致命；「同家族模型背错同一知识」的风险靠检索证据兜住大半。
**成本**：拆开 = 核验只对有承重断言的章触发，审校 merge 前集中做，各花各的钱。
技术通路（调研实证）：`PluginContext.get_model_access` → `ModelAccess.invoke_text`，
不进主对话流，支持 JSON 输出。

## 议题 ③ 引用标记格式

**定稿：顺序编码制 [n]，无悬念。**三个理由（用户原判）：

1. **表格撑不肿**：对标表格子就是 `39.3%[12]`；著者-出版年制下 10×6 表格没法看；
2. **检查器是纯集合运算**：[n] 的抽取/悬空判定/孤儿判定全是编号集合比对，正则写完；
   著者-出版年制靠名称归一化，误判漏判工程量翻几倍。选代码能百分之百判对的格式；
3. **假来源表演舞台被拆**：正文只剩 [n]，来源名集中到章末参考资料——核验和检查器有了
   集中靶场，条目强制结构化（机构 + 报告名 + 年份 + URL/页码），回源核验程序化好接。

**实现钉两条**：

1. **全书统一编号池**：同一来源全书一个号；章末只列本章用到的条目，附录列总表；
2. **台账加 ref 编号列，当编号注册中心**：新增来源先在台账登记取号，正文再用号——
   编号分配有机制支撑，不靠模型记忆，杜绝重号。

**读者成本缓解**：条目首字段永远是机构名（同一来源反复出现，读者翻一两次就记住编号）。

## 议题 ④ 续写前台化后的诚实出口

**定稿三句话**：

1. **叫停双通道**：模型可主动申请「扩无可扩」（常态机制，不是耗到轮尽的被迫承认）+
   **3~4 轮硬上限**（兜底，到顶自动开出口）。不上同事的 8 轮——round 场景实证第三轮只涨
   600 字、边际收益枯竭，且续写越多拼接病越重；
2. **出口 = 举证制**：progress.md 必须写明大纲要点 → 小节的覆盖映射 + 实际/目标字数 +
   不足原因；**merge 前审校链核举证**（要点是否真有对应小节与实质内容，防「标题有内容空」
   骗出口）；P7=0 + 举证可信 → 记「合规但记录」放行；
3. **预算分账**：修复 N=2（犯错保险）与续写 ≤3~4 轮（工作量预算）**各算各的，不共用**——
   共用会让「修错」和「补写」两种正当需求互相抢额度；退化检查器全程守卫，
   续写不免质量责任（续写是复制粘贴高发区）。

## 二、各章要点与数据来源计划

### 第1章 研究背景、方法与数据来源说明
- 1.1 研究背景：地产下行、LED替换周期结束、智能照明渗透、出海与内卷
- 1.2 研究问题与竞品选择标准（可比性、渠道重合、资本属性、技术路线）
- 1.3 方法论：桌面研究、年报解剖、参数矩阵、五力/SWOT、口径与证据分级
- 1.4 数据来源与局限：上市公司年报、行业协会、标准文本、媒体；[待核实]规则
- 数据来源计划：欧普2025年报、佛山/三雄/公牛/木林森2025年报、行业报道

### 第2章 全球与中国照明行业全景
- 2.1 全球照明市场规模与格局（Signify、ams-OSRAM、木林森/朗德万斯）
- 2.2 中国照明产业规模与结构（总产值、LED通用照明、出口）
- 2.3 需求结构：家居、商用、工业、户外、汽车、特种
- 2.4 政策与标准：能效标准、双碳、绿色建材、智能互联标准
- 图表：市场规模柱状图、产业链示意、需求结构表
- 数据来源计划：证券日报/CSA、三雄极光2025年报、Signify/ams-OSRAM年报、国标文本

### 第3章 欧普照明公司深度剖析
- 3.1 发展历程与关键节点（1996创立、2016上市、2025品牌OLL与复旦实验室）
- 3.2 股权结构与治理（实控人、管理层、分红与回购）
- 3.3 业务结构与商业模式（家居/商照/电商/海外，自制+OEM）
- 3.4 财务解剖（2021—2025营收、利润、毛利率、费用、现金流、存货）

- 数据来源计划：欧普2023/2024/2025年报、官网、券商点评

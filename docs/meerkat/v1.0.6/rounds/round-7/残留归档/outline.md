# 《欧普照明竞品分析深度研究报告》写作大纲

- 报告题目：欧普照明竞品分析深度研究报告——通用照明存量竞争下的龙头位置、竞品拆解与战略路径
- 研究对象：欧普照明股份有限公司（Opple Lighting，603515.SH）
- 对标对象：雷士照明（NVC，中国雷士，非上市）、佛山照明（000541.SZ）、三雄极光（300625.SZ）、阳光照明（600261.SH）、公牛集团（603195.SH，含沐光）、木林森（002745.SZ，含朗德万斯 LEDVANCE）、昕诺飞（Signify，LIGHT.AS）、艾迈斯欧司朗（ams OSRAM，AMS.SW）、松下照明（Panasonic，中国区）、Yeelight 易来（青岛易来智能）
- 数据基准：以各公司最新一期已披露定期报告为准；A 股公司以 2025 年年度报告为财务基准年，辅以 2026 年三季报作为最新经营状态；境外公司以 2025 财年为基准
- 全文目标：非空白字符数 ≥100,000；各章下限合计 110,000

## 一、章节结构、要点与下限分配

- 第1章 研究背景、方法与数据来源说明：≥6,500字
  - 1.1 研究缘起：通用照明进入存量出清期，龙头位置被动摇
  - 1.2 研究问题与四个分析层次（行业—公司—竞品—战略）
  - 1.3 研究方法：财务对标、产品参数矩阵、渠道结构分析、五力/SWOT/战略群组
  - 1.4 数据来源与口径规则（合并报表/单季/财年、汇率、份额分母）
  - 1.5 报告结构与阅读指引
  - 1.6 研究局限与待核实事项说明
  - 数据来源计划：各公司年报、CSA/中国照协、欧睿、集邦
- 第2章 中国及全球照明行业全景：≥9,000字
  - 2.1 全球照明市场规模与结构（LED 渗透、区域分布）
  - 2.2 中国照明产业规模：总产值、下游应用、通用照明三段数据
  - 2.3 出口：连续四年下行与结构变化
  - 2.4 供给端：规上企业数量、亏损面、产能利用率
  - 2.5 需求端：地产链、城市更新、存量替换、以旧换新
  - 2.6 政策与标准：能效标准、双碳、智能照明标准、适老照明目录
  - 2.7 产业链利润分布：芯片—封装—应用
  - 2.8 行业周期判断
  - 数据来源计划：CSA 蓝皮书、中国照协运行数据、海关总署、集邦、观研天下
- 第3章 欧普照明公司深度剖析：≥10,000字
  - 3.1 发展历程与关键节点（1996—2026）
  - 3.2 股权结构与治理（中山欧普投资、王耀海、马秀慧）

  - 3.4 财务分析：营收、利润、毛利率、费用、现金流、应收、存货
  - 3.5 研发与技术体系（SDL、清澈光、天境、专利、研发投入）

  - 3.7 战略路线与“全球第一智能照明品牌”愿景的可行性
  - 3.8 风险点：质量抽检、现金流、跨界竞争
  - 数据来源计划：欧普 2025 年报、2026 三季报/半年报、官网、投资者记录、监管通报
- 第4章 竞争格局总览与五力分析：≥7,500字

## 四、写作纪律

1. 每章独立文件，单次 write_file 只写一节（2,000—4,000 字），一章分 3—5 次写完。
2. 每章写完立即用 report_stats 实测，未达下限则围绕本章要点追加新节/新段，不推倒重写。
3. 所有关键数值同步登记 data_ledger.md，ref 编号全书唯一。
4. 每张表/图后必须有 `> 数据来源：[n]` 与 ≥2 句解读。
5. 查无实证的数据标 `[待核实]`，并在第 13 章汇总。
6. 章末必设 `## 本章参考资料`，只列本章引用条目，正文编号与条目双向闭合。

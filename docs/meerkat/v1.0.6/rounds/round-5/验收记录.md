## 四、模型侧问题清单（Meerkat-TRIZ-v1，系统性退化）

1. 重复输出退化 ×2（同一段逐字重复 3 次）；
2. 空响应 ×4（1 次停摆 26 分钟，3 次连续直接终结会话）；
3. 核验判定输出冗长，反复撞长度上限（每条判定 5~8 分钟 + 重试）；
4. 编辑工具使用不当：修台账只会追加不会替换；write_file 误将台账 412 行截断为 3 行。

## 五、harness 侧候选改进（轮后讨论，按优先级）

1. **空完成护栏**：API 成功但内容为空 → 告警/自动重试/记事故（本轮 26 分钟纯停摆 +
   最终致命三连空，都是这个洞）；
2. **重复输出检测**：assistant 连续逐字重复 → 判退化、告警；
3. **核验判定调用约束**：结构化输出强约束 / max_tokens 调优，或配 OCTOP_VERIFY_MODEL
   独立 judge，与主模型退化解耦；
4. **write_file 防护**：大文件覆写前体量比对，异常收缩（412→3）拒写或告警；
5. **检索冗余**：searchfree 单点瞬时故障可配 tavily/brave 兜底（registry 已支持）。

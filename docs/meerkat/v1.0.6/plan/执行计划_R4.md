## Global Constraints

- **Octop 内核零改动**；不动 `main`/`meerkat` 分支；开发在 `feature/triz`；commit 用 conventional prefix + 中文 message。
- `LEDGER_FIELDS`（report_qa/constants.py:11）**不动**；台账 ref 列是推荐列，由检查器单独判定。
- 引用检查**双样式永久并存**：旧式「数据来源：」标注与新式 `[n]` 都合法，永不下线旧式。
- 看门狗默认超时 **300s**（env `OCTOP_MODEL_WATCHDOG_TIMEOUT_S`）；开关 `OCTOP_MODEL_WATCHDOG_ENABLED=1`。
- 核验调用自身超时 **120s**、重试 **2 次**指数退避；一般数值抽检**每章至多 3 条**；续写硬上限 **3 轮**。
- 独立核验/审校模型走 env `OCTOP_VERIFY_MODEL`，缺省回落主模型。
- 金缺陷编号：GD-21 占位符、GD-22 虚构来源、GD-23 悬空引用、GD-24 孤儿条目、GD-25 未注册编号、GD-26 负号冲突、GD-27 同章反复。

- 测试命令统一 `python -m pytest <path> -v`（仓库根、已配 conftest）。

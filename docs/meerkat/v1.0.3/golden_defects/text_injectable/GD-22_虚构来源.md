# GD-22：虚构来源/事实（核验工序应判证伪/查无实证）

## 缺陷描述

正文写出格式完美但来源与事实均为虚构的承重断言——段内标注、口径、编号样样齐全，
但「上市地/年份/报告名」全是编的。检查器层（格式类）对它无能为力，必须由核验工序
（检索 → 抓正文 → 模型比对）判定证伪或查无实证。

## 注入形态

text_injectable：向章节正文追加虚构承重断言段落。回归以 mock 检索层接入
（桩 model_access 判定 + 桩 search/fetch），不碰真模型/真网络——回归测的是
「断言 → 判定 → 章置 dirty」的接线，不是模型的判断力。

## 期望命中

`verification` 通路产出 check="verification" 的证伪 finding（章置 dirty）。

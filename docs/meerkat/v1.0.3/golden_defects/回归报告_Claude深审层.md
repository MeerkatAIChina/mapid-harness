### GD-08 份额倒挂（隐含分母不一致）✅ 检出

**报告数据**（L4188-4189 注入 / L1785-1786 原生表 4-1）：佛山照明 90.48 亿 / 1.27%；公牛集团（照明业务）83.31 亿 / 1.31%。

**核查结果：内部算术矛盾。**

- 佛山：90.48 ÷ 1.27% → 隐含市场规模 **≈7,124 亿**
- 公牛：83.31 ÷ 1.31% → 隐含市场规模 **≈6,359 亿**
- 同一张表内两行的隐含分母相差 **765 亿**（12%）；营收更高者份额反而更低，逻辑倒挂。要么份额算错、要么两行分母口径不同且未声明——无论哪种都是一致性缺陷。

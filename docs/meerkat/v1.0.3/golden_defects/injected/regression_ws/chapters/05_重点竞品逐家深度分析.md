## 5.1 雷士照明（NVC Lighting）

### 5.1.1 公司概况

雷士照明（NVC Lighting）是中国照明行业的标志性品牌之一，成立于1998年，总部位于广东省惠州市。雷士照明由吴长江创立，曾是中国照明行业的领军企业，以"雷士照明，创造绿色照明"为品牌理念，在家居照明和商业照明领域具有广泛的市场影响力。

雷士照明于2012年12月在港交所上市（股票代码：2222.HK），成为"中国照明第一股"。然而，上市后公司经历了复杂的股权争夺和管理层动荡。2017年，雷士照明从港交所退市，被吴长江管理团队收购。退市后，雷士照明的财务数据不再公开披露，其经营状况和市场地位发生了一定变化。

## 5.11 本章小结

本章对10家重点竞品进行了逐家深度分析，包括雷士照明、佛山照明、三雄极光、公牛集团、阳光照明、木林森、飞利浦照明/昕诺飞、松下照明、Yeelight/小米生态链、欧司朗/艾迈斯欧司朗。主要结论如下：

**第一，中国照明行业竞争格局多元化。** 传统照明品牌（欧普、佛山、三雄极光）、跨界竞争者（公牛集团）、互联网品牌（Yeelight）、国际品牌（昕诺飞、松下、欧司朗）共同构成多元化竞争格局。

**第二，公牛集团是最大威胁。** 公牛集团以168.31亿元的营收和42.72亿元的归母净利润，展现出强大的综合竞争力。其智能电工照明业务营收83.31亿元，同比增长5.42%，对传统照明企业构成直接威胁。

**第三，传统照明企业面临转型压力。** 欧普照明、佛山照明、三雄极光等传统照明企业面临营收下滑、利润承压的挑战，需要加速智能照明、健康照明等新兴领域的布局。

**第四，互联网品牌和跨界竞争者正在重塑行业格局。** Yeelight/小米生态链以智能+性价比优势进入市场，公牛集团以渠道+品牌优势进入市场，正在重塑行业竞争格局。

**第五，国际品牌在中国市场面临本土化挑战。** 昕诺飞、松下、欧司朗等国际品牌在中国市场主要面向高端专业市场，与本土品牌形成差异化竞争，但品牌认知度和渠道覆盖不如本土品牌。

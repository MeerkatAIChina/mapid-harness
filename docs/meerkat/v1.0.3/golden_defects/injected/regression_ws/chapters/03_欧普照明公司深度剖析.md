# 第3章：欧普照明公司深度剖析

## 3.1 公司发展历程与里程碑

### 3.1.1 创业起步阶段（1996-2008年）

欧普照明股份有限公司（Opple Lighting Co., Ltd.）的起源可以追溯到1996年。创始人王耀海、马秀慧夫妇在广东省中山市古镇——这个被誉为"中国灯饰之都"的地方，创建了一家小型照明灯具工厂。

中山市古镇是中国最大的照明灯具生产基地，拥有完整的产业链配套和成熟的产业集群。1996年，中国照明行业正处于卤素灯、荧光灯等传统光源主导的时代，LED照明尚未普及。王耀海夫妇敏锐地捕捉到了家居照明市场的巨大潜力，从最基础的吸顶灯、筒灯等产品入手，开始了创业之路。

**表3-1：欧普照明发展历程关键里程碑**

| 时间 | 里程碑事件 | 战略意义 |
|------|-----------|----------|
| 1996年 | 王耀海、马秀慧在中山古镇创建工厂 | 创业起步，切入家居照明市场 |
| 1999年 | 购置厂址建设厂区 | 扩大产能，建立生产基地 |
| 2004年 | 在迪拜成立首家海外分公司 | 开启国际化布局 |
| 2005年 | 中山工业园开始建设 | 产能规模化，商照/电工产品全线上市 |
| 2008年10月 | 公司正式工商注册成立 | 规范化运营 |
| 2009年 | 总部迁至上海 | 提升品牌高度，靠近资本市场 |
| 2012年 | 吴江工厂投产 | 产能进一步扩张 |
| 2013年 | 研发中心搬迁至吴江工厂，初步建立专利体系 | 强化研发能力 |

| 2021年 | 华南园区破土动工 | 产能布局优化 |
| 2023年3月 | 与华为云签署全面合作协议 | 数字化转型，智能照明布局 |
| 2023年 | 布局智慧消防 | 业务多元化拓展 |

| 2025年8月 | 发布2025年半年度报告，营收32.16亿元 | 持续经营 |
| 2026年2月 | 入选国家知识产权示范企业创建对象名单 | 创新能力获国家认可 |

**解读：** 欧普照明的发展历程清晰地反映了中国照明行业的变迁轨迹。从1996年创业起步，到2005年产能规模化，再到2016年上市资本化，欧普照明始终紧扣行业发展脉搏。特别是2009年总部迁至上海，标志着公司从"制造型企业"向"品牌型企业"的战略转型。2016年上市后，欧普照明借助资本市场力量，加速了品牌建设、渠道拓展和技术创新。

### 3.1.2 LED转型与品牌崛起阶段（2009-2016年）

2009年，欧普照明将总部从中山迁至上海，这一决策具有深远的战略意义。上海作为中国金融中心，不仅便于公司接触资本市场，更有助于提升品牌形象。与此同时，欧普照明开始全面推进LED照明转型，从传统光源向LED光源过渡。

2012年，欧普照明吴江工厂投产，产能规模进一步扩大。2013年，研发中心搬迁至吴江工厂，公司初步建立了专利体系，标志着欧普照明从"制造驱动"向"研发驱动"的战略转型。

2016年8月，欧普照明在上海证券交易所主板上市（股票代码：603515），成为"中国家居照明第一股"。上市融资为欧普照明提供了强大的资金支持，公司得以加速渠道建设、品牌营销和技术创新。

|------|-----------------|-------------------|--------|--------|
| 营业收入（亿元） | ~55 | ~60 | ~65 | ~68 |
| 归母净利润（亿元） | ~7.5 | ~8.0 | ~8.5 | ~8.8 |

**解读：** 上市后，欧普照明的财务表现整体稳健。2016-2018年，公司营收保持5-8%的年均增速，毛利率稳定在38-40%区间，研发费用持续增加，反映出公司对技术创新的重视。

### 3.1.3 多元化与智能化发展阶段（2017年至今）

2017年以后，欧普照明进入了多元化与智能化发展的新阶段。公司不再局限于传统的家居照明业务，而是积极拓展商业照明、电工电气、智能照明等新兴业务领域。

2019年，欧普照明成为北京世园会植物馆战略合作伙伴，并担任2020年迪拜世博会中国馆官方合作伙伴及指定照明解决方案提供商，品牌影响力显著提升。

2021年，欧普照明华南园区破土动工，进一步优化产能布局。2023年3月，欧普照明与华为云签署全面合作协议，标志着公司在数字化转型和智能照明领域的重大布局。同年，公司开始布局智慧消防领域，探索业务多元化。

2024年，欧普照明实现营业收入70.96亿元，同比下降8.96%；归母净利润9.03亿元，同比下降2.28%。尽管面临业绩下滑的压力，公司仍稳居中国家居照明领域第一梯队。

2025年8月，欧普照明发布2025年半年度报告，实现营业收入约32.16亿元，同比下降4.46%；归母净利润约3.69亿元，同比下降4.07%。连续两个季度的业绩下滑，反映出公司面临的挑战。

2026年2月，欧普照明入选国家知识产权示范企业创建对象名单，获得浦东新区ESG引领样本荣誉，创新能力和社会责任表现获国家认可。2026年3月，欧普照明携旗下设计品牌OLL亮相德国法兰克福国际灯光照明及建筑技术与设备展，国际化品牌战略持续推进。

**解读：** 欧普照明的成长性指标在2024年出现明显下滑。营收增速从2023年的7.27%转为-8.96%，净利润增速从17.84%转为-2.28%。这一变化主要受宏观经济环境、房地产行业低迷、消费疲软等因素影响。需要关注的是，扣非净利润增速-11.97%低于净利润增速-2.28%，反映出非经常性损益对利润的支撑作用。

## 3.10 本章小结

本章系统剖析了欧普照明的公司发展历程、股权结构、组织架构、产品矩阵、生产基地、研发体系、财务表现和核心竞争力。主要结论如下：

**第一，欧普照明是中国照明行业的标志性企业。** 从1996年创业起步到2016年上市，公司经历了从制造驱动到品牌驱动再到技术驱动的演变，已成为中国家居照明领域的第一梯队企业。

**第二，欧普照明的财务表现整体稳健但面临挑战。** 2024年营收70.96亿元，同比下降8.96%；归母净利润9.03亿元，同比下降2.28%。毛利率39.3%，净利率12.7%，均高于行业平均水平。但营收连续两年下滑，研发费用大幅下降，反映出公司面临的压力。

**第三，欧普照明的核心竞争力体现在品牌、渠道、产品、研发等方面。** 品牌知名度高，渠道网络密集，产品矩阵全面，研发能力较强。但同时也面临营收下滑、研发下降、渠道依赖、品牌定位、国际化程度不足等挑战。

**第四，欧普照明的未来战略规划聚焦智能照明、健康照明、国际化、数字化转型等方向。** 这些战略方向紧扣行业趋势，有助于公司应对挑战、把握机遇。

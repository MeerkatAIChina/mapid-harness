# 过程性缺陷清单（process_checklist）

这些缺陷发生在**执行过程**而非文本产物中，无法注入文本让评审链检出，
由各自机制的验收项覆盖：

| ID | 缺陷 | 验收覆盖 |
|---|---|---|
| PC-01 | stream_error 断流需人工继续 | T4：模拟断流无人干预恢复（收敛条件5） |
| PC-02 | 长期记忆污染新任务 | T5：Loop① 准备检查单（记忆隔离） |
| PC-03 | 自写合并脚本产出损坏 | T2：merge_chapters 体量校验拦住膨胀 |
| PC-04 | 运行时日期缺失 | T5：日期注入后落款正确（文本表现由 GD-16 覆盖） |

每轮 Loop 的 ① 准备阶段过一遍此清单，确认各机制的验收项仍有效。

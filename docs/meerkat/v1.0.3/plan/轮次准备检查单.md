# 轮次准备检查单（Loop ① 准备阶段）

> 版本：v1.0.3 · 2026-10-19
> 用途：每轮调优（快速轮 / 全量轮）开跑前逐项执行，保证实验卫生——轮间唯一变量是「改动包」，不是残留状态。
> 每轮把本清单复制到 `rounds/round-N/准备检查单.md`，逐项打勾存档。

## 1. 记忆隔离（防长期记忆污染新任务，对应 PC-02）

- [ ] 确认 Octop 服务已停止或实验 agent 空闲（`memory.sqlite-wal` 非空 = 数据库在用）
- [ ] 归档上一轮长期记忆：
  ```powershell
  python E:\projects\mapid-harness\scripts\reset_agent_memory.py `
      --octop-home E:\projects\meerkatai-octop\.octop-dev --agent-id <实验AgentId>
  ```
  （默认归档到 `.octop/memory_archive/<时间戳>/`，可回滚；`--delete` 直接删除）
- [ ] 如需对照实验保留旧记忆，跳过归档但在本轮记录中注明「记忆未隔离」及理由

## 2. 会话隔离

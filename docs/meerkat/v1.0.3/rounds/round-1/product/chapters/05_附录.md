## 5.2 术语表

| 术语（中文） | 术语（英文） | 定义 |
|-------------|-------------|------|
| LED | Light Emitting Diode（发光二极管） | 一种固态半导体器件，可将电能直接转化为光能 |
| CRI | Color Rendering Index（显色指数） | 衡量光源还原物体真实颜色能力的指标，范围 0–100 |
| 光效 | Luminous Efficacy（光效） | 光源发出的光通量与消耗电功率之比，单位 lm/W |
| 智能照明 | Smart Lighting / Intelligent Lighting | 利用物联网、AI 等技术实现照明系统自动化控制的照明方案 |
| 人因照明 | Human Centric Lighting (HCL) | 模拟自然光节律调节色温与亮度的照明技术 |
| 无主灯设计 | No Main Light Design | 以筒灯、射灯、灯带等分散光源替代传统主灯的室内设计风格 |
| UGR | Unified Glare Rating（统一眩光值） | 衡量照明系统眩光程度的指标，UGR<19 为舒适标准 |
| DALI | Digital Addressable Lighting Interface（数字可寻址照明接口） | 国际标准的智能照明通信协议 |
| Matter | Matter（Matter 协议） | 由连接标准联盟（CSA）推出的智能家居互联标准 |
| LiFi | Light Fidelity（光通信） | 利用 LED 光信号进行数据传输的无线通信技术 |
| COB | Chip on Board（板上芯片封装） | 将 LED 芯片直接封装在基板上的技术 |
| SMD | Surface Mount Device（表面贴装器件） | 表面贴装 LED 封装技术 |
| Mini LED | Mini LED（迷你 LED） | 芯片尺寸在 50–200μm 的 LED 技术 |
| Micro LED | Micro LED（微 LED） | 芯片尺寸小于 50μm 的 LED 技术 |
| 吸顶灯 | Ceiling Light / Pendant Light | 安装于天花板的照明灯具 |
| 筒灯 | Downlight / Recessed Light | 嵌入天花板的照明灯具 |
| 射灯 | Spotlight | 定向照明的灯具 |
| 灯带 | LED Light Strip | 柔性 LED 照明产品，可裁剪安装 |
| 电工 | Electrical Accessories | 开关插座、配电箱等电气配件 |
| 工程渠道 | Project Channel | 面向政府项目、商业综合体等 B 端客户的销售渠道 |
| 零售渠道 | Retail Channel | 面向终端消费者的销售渠道（专卖店、电商等） |
| 双碳 | Dual Carbon（碳达峰、碳中和） | 中国 2030 年碳达峰、2060 年碳中和的战略目标 |
| CR5 | Concentration Ratio 5（行业前五集中度） | 行业前五名企业市场份额之和 |
| CR10 | Concentration Ratio 10（行业前十集中度） | 行业前十名企业市场份额之和 |
| ROE | Return on Equity（净资产收益率） | 净利润与股东权益的比率 |
| ODM | Original Design Manufacturer（原始设计制造商） | 为品牌方提供设计与制造服务的企业模式 |
